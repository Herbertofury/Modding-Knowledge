Do not read “requires original configurations” as “enable two DLLs.” The port describes its own replacement plugin and original configuration/model definitions as separate inputs. Do not promote this to an automatic install instruction or infer which author controls a similarly named profile. The [original INI helper](https://github.com/Thiago099/Model-Swapper/blob/33fdc9923e3a7a68bb7d1260b2b97adf53a3c2e7/include/Ini.h) shows a Unicode load under `Data/SKSE/Plugins`; it alone does not establish a filename pattern, grammar, precedence, or a swap winner. A file watcher can preserve this observed directory, but should not classify every INI there as Model Swapper.

The observation pack preserves scope and independent source provenance. Unverified relation categories are omitted (unknown, not confirmed none). It is intentionally not added to the generated bundle, live scheduler or downloader. Files, media, accounts and user data were neither downloaded nor modified.
