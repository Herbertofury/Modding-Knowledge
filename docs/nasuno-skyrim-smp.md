# nasuno04 Skyrim SMP projects

The creator's [SkyrimSE HDT-SMP site](https://nasunosakuragawa.blogspot.com/) and
eight individual articles identify [@nasuno04](https://x.com/nasuno04). This
links public publishing identities; it does not infer a legal identity or
inventory of every release. Site access was throttled during a fresh homepage
request. Individual indexed creator pages were usable, so no workaround or
retry was needed.

This batch keeps CS/PBR and Vanilla/ENB releases separate, and keeps legacy
BHUNP variants distinct from current 3BA variants. For the [Mage's Daily
Outfit patch](https://nasunosakuragawa.blogspot.com/2025/09/mages-daily-outfit-smp-patch.html),
the author credits Suna203 and nasuno04 and explicitly requires the main file.
For [saLaHairs](https://nasunosakuragawa.blogspot.com/2023/04/salahairs-se-smp-1-3.html),
the author excludes Skyrim LE and VR. The [Kanrax2 dress](https://nasunosakuragawa.blogspot.com/2024/11/kanrax2-sleeveless-dress-smp-0-1-3ba.html)
has desktop SE/AE author labels and a tentative VR condition, not a VR acceptance
test. The [Warlock robes](https://nasunosakuragawa.blogspot.com/2024/11/vanilla-warlock-robes-smp-3ba-bhunpv4.html)
have a separate author-stated VR claim. Keep those claims separate.

Routes link to the published author article, not undisclosed Drive IDs,
mirrors, cookies, binaries, or store credentials. The article's Drive or
Nexus availability, file age and exact game builds are unverified. The
coauthor's rights, original assets and any release dates beyond the published
evidence are not inferred from the creator's modification notes.

```sh
cargo run --locked --example seed_reviewed_bundle -- --skyrim-nasuno-smp skyrim-nasuno-smp.sqlite
```

This builds a separate catalogue; no auto-download, license transfer, account
follow, user file edits, runtime installation or game tests are performed.
