This repository is the shared home for structured creator/mod/tool/troubleshooting knowledge. Athena is a consumer, not the sole storage location. Read database observations together with their source, game/runtime, mod version, date, completeness and conditions.

## Start here

1. Download the populated snapshot or build it with the native Rust importer.
2. Verify its digest, integrity and schema before using it.
3. Keep provider claims distinct from independently tested behavior.
4. Preserve the previous snapshot when an update fails.

This wiki source is version-controlled with the data. It does not claim GitHub's separate live Wiki has been synchronized.
